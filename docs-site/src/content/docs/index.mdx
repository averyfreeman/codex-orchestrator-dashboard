The Codex Orchestrator Dashboard gives an operator one local view of Codex app-servers, Herdr sessions, Treehouse worktrees, and optional OpenClaw gateway status. Its control plane can start and interrupt a Codex turn, manage named Herdr sessions, and request a guarded daemon start when a host is down.

The **dashboard is a self-hosted Next.js application**. The public GitHub Pages site is a separate static operator and maintainer guide; it has no fleet inventory, credentials, or live control API.

## What runs where

The browser talks to a loopback-only Next.js gateway. The gateway reads bounded host metadata over local probes or strict SSH, and it starts a host-scoped Codex app-server bridge only when the operator chooses to send a prompt. SSH tries configured routes in order: use ZeroTier first and Tailscale as failover. Private host inventory and SSH keys stay on the gateway host.

For deployment, GitHub Pages builds only this documentation tree. Next.js request-time route handlers, streaming turns, and local file-backed telemetry remain on the operator’s machine. See [why the app is self-hosted](./maintainers/architecture/#deployment-boundary).
